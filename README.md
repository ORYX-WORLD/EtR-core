# EtR-core

Système embarqué EtR de supervision Raspberry Pi : Flask, Modbus, capteurs,
portail Wi-Fi tactile, affichage SPI et accès distant sécurisé.

## Traçabilité

Chaque livraison suit la chaîne : issue → branche → pull request → commit →
version → manifeste de déploiement → validation de la cible.

- Version courante : [`VERSION`](VERSION)
- Changements : [`CHANGELOG.md`](CHANGELOG.md)
- Contribution : [`CONTRIBUTING.md`](CONTRIBUTING.md)
- Définition de terminé : [`docs/definition-of-done.md`](docs/definition-of-done.md)
- Décisions d'architecture : [`docs/adr/`](docs/adr/)
- Incidents : [`docs/incidents/`](docs/incidents/)
- Registres : [`docs/registers/`](docs/registers/)
- Manifestes de déploiement : [`docs/deployments/`](docs/deployments/)

Les preuves générées par la CI sont conservées comme artefacts GitHub Actions ;
elles ne sont pas réécrites automatiquement dans la branche `main`.
