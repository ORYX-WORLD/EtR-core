# Registres opérationnels

| Registre | Source de vérité | Responsable | Revue |
| --- | --- | --- | --- |
| Besoins et anomalies | GitHub Issues / Project | Product owner | Hebdomadaire |
| Versions | `VERSION`, tags et Releases | Mainteneur | À chaque release |
| Changements | `CHANGELOG.md` | Auteur / reviewer | À chaque PR |
| Décisions | `docs/adr/` | Architecture | À chaque décision |
| Déploiements | Artefacts GitHub Actions | Exploitation | À chaque déploiement |
| Incidents | `docs/incidents/` | Incident owner | Après incident |
| Parc installé | `device-fleet.csv` | Exploitation | Mensuelle |
| Risques | `risk-register.md` | Direction technique | Mensuelle |

Les identifiants de machines sont des identifiants métier ; aucune adresse, clé,
adresse IP privée ou donnée personnelle ne doit apparaître ici.
