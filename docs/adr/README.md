# Registre des décisions d'architecture

Une ADR documente une décision structurante, son contexte, les alternatives et ses
conséquences. Elle est numérotée, relue en pull request et n'est plus modifiée après
remplacement : une nouvelle ADR la déclare alors « remplacée ».
